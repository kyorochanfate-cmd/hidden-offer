# 非公開求人 — The Hidden Offer

現代サバイバル・社畜疑似体験ミニゲーム集（プロトタイプ）。

## プレイ

GitHub Pages で公開中 → デプロイ後にURLが入ります。

スマホ縦持ち推奨。

## 構成

- メニュー / ガチャ（キャリアコンサル）/ コレクション → ピクセル・ネオン路線
- **パワーポッター** → 実在オフィスソフトの忠実再現UI上で、上司の理不尽な指示に応答する作業シミュレーター
- ChatRally / Jiggler / Exchange → 実装予定

## 開発

依存ゼロ。`python -m http.server 8765` でローカルサーバーを起動して `http://localhost:8765/` を開く。
